# rosbiotech-studies

Учебная база знаний РОСБИОТЕХ. Этот файл нужен только для навигации по организации; рабочие правила находятся в соответствующих репозиториях.

## Быстрый маршрут

- Если задача относится к конкретной дисциплине — найди её в списке ниже, открой предметный репозиторий и прочитай его `.studyrepo.yml`, `README.md` и `AGENTS.md`.
- Не исследуй остальные репозитории без необходимости.
- Если задача относится к устройству организации, общим правилам или фоновой синхронизации — начни с `automation`.

Служебные репозитории:

- `automation` — общие стандарты, проверки и production-сценарии;
- `inbox` — пользовательский вход для быстрой загрузки исходников; штатно обрабатывается фоновой синхронизацией;
- `inbox-bot` — интерфейс загрузки материалов в `inbox`;
- `subject-template` — шаблон нового предметного репозитория.

`inbox` не является обязательным промежуточным шагом, если пользователь уже поручил непосредственно обработать и сохранить материал в конкретную дисциплину.
