# ROSBIOTECH Studies

Учебная база материалов и конспектов РОСБИОТЕХ.

Каждая дисциплина хранится в отдельном предметном репозитории. Внутри занятий сохраняются исходные материалы (`sources/`) и общий актуальный конспект (`notes.md`).

## Как пользоваться

- **Найти материалы** — откройте репозиторий нужной дисциплины.
- **Быстро добавить исходники** — используйте `inbox` или Telegram-бот; дальнейшую обработку выполнит система.
- **Работать через ChatGPT / Codex** — можно сразу назвать дисциплину и занятие; если текущий контекст не указан, система при необходимости использует актуальный семестр и расписание по canonical rules.

Общие стандарты и автоматизация системы находятся в `automation`.
